## P0/P1 修复清单（全部有实机验证）

1. **DI 账本拆分**（最重，两份共识）：决策场含 DI（动力学不变），账本只记
   保守部分（θ/W/Γ，恰好是 energy() 的差分）；DI 做功独立记 driveWork；
   最优回退按真实能量；返回如实带 converged/terminationReason/residualFlips；
   淬火预算逐翻转严格检查。池电路专属开关 fallbackQuietOnly：回退只在
   驱动静息态中选（多核共存态真实能量更低但破坏 WTA 语义——驱动静息期
   最低能态才是非平衡系统的代表态）。评审复核：energyTraceMismatch 0/734。
2. **核生命周期事务化**：注册以规则注册表为准（与签名分配解耦）——
   先侧重后观察不再漏登记；元数据随再观察并集更新；FieldRuleMemory 容量
   边界显式抛错（修复前越界核静默覆盖抑制池神经元）；全空预测不再白占核。
3. **R2 窗口诚实化**：分层结果自校验（交集成员必须全部驻留，否则降档重试，
   至多 3 次后如实报 undecidable）；恒定结果的对不再误报变化/因素。
4. **点火不等式参数化**：写入重复数由 coreSize/popSize/η/θ 推导下限——
   修复前默认写入强度（0.2 边）支撑不起单核点火结果群体（1.4<θ=1.5），
   五个小新世界四个全读空；修复后默认配置全部读回。
5. **"每次实验都是证据"**：探索闭环不再"符合不写"（修复前留下有侧重无结果的
   空核，被证据过滤后该条件只能由近似核代答）。
6. **WTA 诚实化**：互抑双写修复 + Γ=6 的迟滞语义保留 + 等强平局由
   lastSelectionTied 如实上报（选择"神经候选筛选+读出层择优"的诚实框架——
   严格 Γ 唯一性会杀死迟滞裕度，二值活动本就不能比较近平局，如实声明）。
7. **输入校验**：越界索引曾别名破坏 W 对称性、NaN 绕过一切比较——公共
   写边入口/配置/钳制/实验台全部拒绝且零部分写入。
8. **场级否决根因修复**（机制级，评审最重发现）：否决边只从"该维已观察
   替代值的感受野"写（与 Pop 版只否决已观察替代档对齐）——修复前从该维
   全部非己感受野写入，未观察区域的输入把所有核压灭。独立复核（评审 1 的
   harness 原样重跑）：同量程网格外 128 随机探针粗粒度 **12.5% → 79.7%**
   （最近邻基线 81.3%），且网格上模型反超基线（100% vs 93.3%）。

## 撤回/降级的声明（诚实清单）

- **"heldout 粗粒度 ≥93%"撤回**：原 heldout 桶按构造恒亮（常数基线 100%）。
  口径改为"全部未观察"桶 + gate-off/gate-on 子集 + 常数基线 + 拒答率，
  重测数字见下表。
- **"0.5 阈值自己结晶"降级**：候选点恰好含 0.5，任意 (0.1,0.5] 阈值产生
  相同观察——可辨识性不成立。保留的合法声明：门控两侧经验区各自结晶。
  阈值精确发现的验证需隐藏随机阈值 + 主动边界逼近（列为后续）。
- **"WTA 动力学择出唯一焦点"降级**为候选筛选+读出择优（平局如实上报）。
- **"G=0 断 R2B 侧重/否决"更正**：修复前只断了加分。2×2 消融重测见下。
- **"概念更新是安全空操作"更正**：周期刷新会重复写权重；重形成步的当步对
  曾被二次处理（已修）。
- **候选域"硬保证"/"全局最小"措辞修正**：冻结只在 quenchCandidatesOnly
  下成立；退火是有限预算近似（反例留在测试集）。
- **"全部由能耗规律涌现"改为**：能耗动力学 + README 先验清单（明确列出）。
- **神经注意力 runner 修复**：预测改为上一帧生成并缓存（修复前到当前帧
  用当前权重重算旧条件）；焦点择选移到帧首且门控下帧预测生成（修复前
  焦点只做日志）。修复后焦点序列不变、准确率 80%→90%。

## 不修复而声明边界的（有依据）

- 非平稳真值反转（B06）：双向纠错否决累积后如实报歧义——非平稳边界，
  当前验收场景（确定性静态世界）之外。
- 退火不保证全局最小（A20）：有限预算近似搜索是声明过的语义。
- 等强候选的 WTA 平局：二值活动无法比较近平局（物理边界），如实上报。
- 远域扩展的致盲：感受野重叠容忍只覆盖相邻扩展（量程扩展实验结论）。
- 历史冻结层 prototype/layers 的简化声明照旧（直连/预置 Γ 属其自身设计，
  文档早已声明）。
