# 自主探索验收（阶段 A）：无教师的陌生场景规则发现

日期：2026-09-18。代码：`src/pop/explore/`（planner + explorer）+ `src/topics/lab-world.ts`，
运行 `npm run exp:explore`（SEEDS 环境变量可选种子），日志 `runs/explore-lab-seed*.log`。

## 验收设定

- **场景**：电路实验台世界——合取门控（亮 = 闭合 AND 有压，第三种门控形态）+
  拮抗因素（电阻拉低亮度）+ 温度小幅加成 + 材料干扰项。与前三主题真值结构全不同。
- **无教师**：无课程、无人工选择学什么。系统只有通用机制（预测核心 + 注意力驱动 +
  控制变量法躯体化为动作空间），规则从零起步。
- **干预接口**：提交完整条件 → 返回真值观察 → 计 1 成本。穷举基线 288 次。
- **闭环**：无知场（无核覆盖，纯边权读出）+ 意外场（偏差邻域增压、随步衰减）
  → 候选干预 WTA 择选（NeuralFocusNet 复用）→ 执行 → 三类判定 → 观察写入（0.6）
  → Hamming-1 自动成对 → R2 差分 → 侧重/否决 → 规则核。终止：无知场全消 +
  连续 8 次验证无偏差。

## 实机结果（3 种子，修复版动力学）

| 种子 | 实验数 | 规则核 | 判定（未知/偏差/符合） | R2 发现因素 | 细粒度 | 粗粒度亮灭 |
|---|---|---|---|---|---|---|
| 1 | 88 | 88 | 35/13/40 | 全 4 因素，material 缺席 | 86.5% | 92.0% |
| 2 | 81 | 81 | 34/17/30 | 全 4 因素，material 缺席 | 86.5% | 92.4% |
| 3 | 68 | 68 | 19/20/29 | 全 4 因素，material 缺席 | 92.0% | 96.9% |
| 均值 | **79（27% 穷举）** | | | **4/4 全对 ×3** | **88.3%** | **93.8%** |

分档（种子 3 为例）：self-taught 91.2%、gate-off 99.4%、heldout 细粒度 72.9%/粗粒度 93.2%。

**验收判据全部达成**：①因素发现 3 种子全对（干扰项全缺席）；②门控两侧自学——
gate-off 最高 99.4%（合取门控的两个关闭支都由偏差事件触发主动复查发现，
轨迹可见：先预测"亮"→观察"灭"→意外场增压邻域→回头扫灭区）；③规则质量
heldout 粗粒度 ≥93%（从未做过的组合上门控逻辑泛化正确）；④效率 79 次实验
vs 穷举 288（27%）vs 教师课程等效约 25-30 次（自主约为教师成本的 3 倍——
教师知道真值能直接挑最有区分度的对，自主系统用实验换信息，这个比值就是
"教师带领是高效特例"的定量证据）；⑤全程无人工干预。

## 过程中发现并修复的缺陷（全部有实机记录）

1. **learnFromObservation 不登记条件档**（自主路径特有）：探索从零起步不经
   teachExperience，observedBins 永远为空、否决边永远不会写入。修复：观察即经验，
   与 teachExperience 同一登记规则。
2. **predict 大核数长尾爬降**（>50 核时单次退火达 5-23s）：两个工程修复——
   候选核按"对钳制输入的 W 支持 > θ/2"过滤（远失配核从静息无点火路径，结构性冻结；
   退火上坡点火理论上存在，实测对结果无影响）；新增 quenchMaxFlips 选项
   （predict 传 8×N，超限回退途中最低能态，语义不变）。种子 2 探索从 1066s → 89s。
3. **运行器可观测性**：逐种子独立落盘 + SEEDS 环境变量分段运行（长任务可恢复）。

## 遗留限制（如实声明）

- heldout 细粒度（亮度档）≈73%：可加合成在未见组合上的最近匹配边界，与化学主题同源。
- 终止判据的效率-精度权衡：50 次实验（修复前种子 1）时 gate-off 只到 78%，
  88 次时 88%——覆盖密度买准确率，判据阈值目前固定（验证 8 连），自适应留作后续。
- 探索仍是**单步**干预选择；多步实验规划（链式生成模拟候选序列）是下一阶段。
- 阶段 B（连续世界+干预，概念自形成接入实验台）未做。
