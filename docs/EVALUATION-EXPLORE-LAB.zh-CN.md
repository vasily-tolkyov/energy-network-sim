# 自主探索验收（阶段 A）：无教师的陌生场景规则发现

日期：2026-09-18。代码：`src/pop/explore/`（planner + explorer）+ `src/topics/lab-world.ts`，
运行 `npm run exp:explore`（SEEDS 环境变量可选种子），日志 `runs/explore-lab-seed*.log`。

## 验收设定

- **场景**：电路实验台世界——合取门控（亮 = 闭合 AND 有压，第三种门控形态）+
  拮抗因素（电阻拉低亮度）+ 温度小幅加成 + 材料干扰项。与前三主题真值结构全不同。
- **无教师**：无课程、无人工选择学什么。系统只有通用机制（预测核心 + 注意力驱动 +
  控制变量法躯体化为动作空间），规则从零起步。
- **干预接口**：提交完整条件 → 返回真值观察 → 计 1 成本。穷举基线 288 次。
- **闭环**：无知场（无核覆盖，纯边权读出）+ 意外场（偏差邻域增压、随步衰减）
  → 候选干预 WTA 择选（NeuralFocusNet 复用）→ 执行 → 三类判定 → 观察写入（0.6）
  → Hamming-1 自动成对 → R2 差分 → 侧重/否决 → 规则核。终止：无知场全消 +
  连续 8 次验证无偏差。

## 实机结果（3 种子，修复版动力学）

| 种子 | 实验数 | 规则核 | 判定（未知/偏差/符合） | R2 发现因素 | 细粒度 | 粗粒度亮灭 |
|---|---|---|---|---|---|---|
| 1 | 88 | 88 | 35/13/40 | 全 4 因素，material 缺席 | 86.5% | 92.0% |
| 2 | 81 | 81 | 34/17/30 | 全 4 因素，material 缺席 | 86.5% | 92.4% |
| 3 | 68 | 68 | 19/20/29 | 全 4 因素，material 缺席 | 92.0% | 96.9% |
| 均值 | **79（27% 穷举）** | | | **4/4 全对 ×3** | **88.3%** | **93.8%** |

分档（种子 3 为例）：self-taught 91.2%、gate-off 99.4%、heldout 细粒度 72.9%/粗粒度 93.2%。

**验收判据全部达成**：①因素发现 3 种子全对（干扰项全缺席）；②门控两侧自学——
gate-off 最高 99.4%（合取门控的两个关闭支都由偏差事件触发主动复查发现，
轨迹可见：先预测"亮"→观察"灭"→意外场增压邻域→回头扫灭区）；③规则质量
heldout 粗粒度 ≥93%（从未做过的组合上门控逻辑泛化正确）；④效率 79 次实验
vs 穷举 288（27%）vs 教师课程等效约 25-30 次（自主约为教师成本的 3 倍——
教师知道真值能直接挑最有区分度的对，自主系统用实验换信息，这个比值就是
"教师带领是高效特例"的定量证据）；⑤全程无人工干预。

## 过程中发现并修复的缺陷（全部有实机记录）

1. **learnFromObservation 不登记条件档**（自主路径特有）：探索从零起步不经
   teachExperience，observedBins 永远为空、否决边永远不会写入。修复：观察即经验，
   与 teachExperience 同一登记规则。
2. **predict 大核数长尾爬降**（>50 核时单次退火达 5-23s）：两个工程修复——
   候选核按"对钳制输入的 W 支持 > θ/2"过滤（远失配核从静息无点火路径，结构性冻结；
   退火上坡点火理论上存在，实测对结果无影响）；新增 quenchMaxFlips 选项
   （predict 传 8×N，超限回退途中最低能态，语义不变）。种子 2 探索从 1066s → 89s。
3. **运行器可观测性**：逐种子独立落盘 + SEEDS 环境变量分段运行（长任务可恢复）。

## 遗留限制（如实声明）

- heldout 细粒度（亮度档）≈73%：可加合成在未见组合上的最近匹配边界，与化学主题同源。
- 终止判据的效率-精度权衡：50 次实验（修复前种子 1）时 gate-off 只到 78%，
  88 次时 88%——覆盖密度买准确率，判据阈值目前固定（验证 8 连），自适应留作后续。
- 探索仍是**单步**干预选择；多步实验规划（链式生成模拟候选序列）是下一阶段。
- 阶段 B（连续世界+干预，概念自形成接入实验台）未做。

# 阶段 B：连续世界 + 干预（概念也要自己结晶）

日期：2026-09-18。代码：`src/pop/explore/explorer-continuous.ts` + `src/topics/lab-continuous-world.ts`，
运行 `npm run exp:explore-cont`（SEEDS 可选），日志 `runs/explore-cont-seed*.log`。

## 验收设定（与阶段 A 的受控对照）

**同一个因果结构**（合取门控 + 拮抗电阻 + 温度加成 + 材料干扰），唯一变量是表征：
条件与结果全部为实数，分档不再给定，值概念必须由系统**自己的实验史**结晶。
两段式闭环：B0 语料相（场级规则记忆直接在感受野上工作，无 R2 无侧重否决）
→ 语料充分性门（每维 ≥2 个观察值）→ 概念形成间歇期（共现成阱 + 对换抑制 →
EmergentMap → R2 通道面 → 全量侧重/持证）→ B2 全机器相（新对即时差分）→ 终止。

## 实机结果（3 种子）

| 种子 | 实验数（语料+全机器） | 规则核 | R2 发现因素 | 细粒度 | 粗粒度亮灭 | gate-off |
|---|---|---|---|---|---|---|
| 1 | 130（34+96） | 85 | 全 4 因素，material 缺席 | 84.0% | 97.9% | 100% |
| 2 | 103（21+82） | 74 | 全 4 因素，material 缺席 | 84.0% | 97.0% | 97.6% |
| 3 | 118（32+86） | 88 | 全 4 因素，material 缺席 | 84.7% | 97.5% | 97.6% |
| 均值 | **117（27% 穷举 432）** | | **4/4 ×3** | **84.2%** | **97.5%** | |

**概念形成报告（种子 1 为代表）**：switchPos 3 概念 [0.1, 0.5, 0.9]（门控阈值 0.5
自己结晶为独立概念）、lit 2 概念 [0.05, 0.95]（二值结果自发结晶）、voltage 4、
resistance/temperature/material 各 3、brightness 2（粗区域合并，"共性先行"形态）。
**A/B 对照（阶段 A 离散给定档 vs 阶段 B 自形成概念）**：同一结构下，自形成表征的
代价是实验数 79 → 117（概念形成需要语料），粗粒度 93.8% → 97.5% 不降反升——
表征可以不由教师分档，由数据自己长出来。

## 阶段 B 过程中发现并修复的缺陷（全部有实机记录）

1. **field-memory 观察核不可见**（严重）：learnFromObservation 给新签名分配核并写全部
   绑定，但从不登记进 rules——predict 候选集只含 rules，空白起步的纯观察学习因此
   全部读空（概念形成时代被预训练覆盖掩盖，注意力时代的新核纠错也从未真正生效）。
   修复：新签名观察核与 teachExperiment 同一登记规则。
2. **field-memory predict 长尾爬降**（与 PopRuleMemory 同病）：候选核按 W 支持 > θ/2
   过滤 + quenchMaxFlips=8×N——predict 从 2-3s 降到 ~0.8s，大核数下不再爆炸。
3. **语料充分性缺失**（种子 2 级联崩溃，最有教育价值的一处）：B0 的验证连胜在单一
   区域提前达成（9 次实验全部 switchPos=0.5），概念形成在零变异维上只成 1 概念，
   R2 差分永远看不到 switchPos → 门控维度漏判 → 下游全崩（300 预算耗尽、4.6%）。
   修复：语料充分性门（每维 ≥2 观察值才允许形成概念）。种子 2 修复后 103 次实验、
   因素全对、97.0%。**教训：控制变量法不只要求"一次变一维"，还要求"每维都变过"——
   这是方法先验的另一半，现在也被躯体化了。**

## 阶段 B 遗留限制

- heldout 细粒度 ≈66%（亮度档连续插值，最近匹配边界，与阶段 A 同源）。
- ~~概念只形成一次（间歇期后不随 B2 更新）~~ **已闭合，见下节"概念更新"**；
  候选值仍来自分位网格（方法先验躯体化），概念中心未用作探针值。
- 单步干预选择；多步实验规划仍是后续。
- 基准重测确认无回归：概念形成 86.7%/98.3%（略升）、神经注意力 t60 85%（持平略升）、
  91/91 → 94/94 测试全绿。

# 概念更新：间歇期后的持续形成（"细分后至"的闭合）

日期：2026-09-19。代码：`explorer-continuous.ts` 的 `shouldReform`/`formConcepts` +
`runner-explore-ext.ts`，运行 `npm run exp:explore-ext`，日志 `runs/explore-ext-*.log`。

## 机制

概念层（EmergentMap）只服务 R2 通道面与解释报告，规则核绑定的是感受野——
**概念随便怎么演化都不损坏任何已学规则**，这是场级规则架构攒下的分离红利。
两个触发（B2 相）：①覆盖缺口——最新实验的某维取值解析不到任何概念；
②周期刷新——每 25 次实验一次（粗概念内部多峰化时的细分机会）。
更新方式：情景缓冲**全量重放**到全新的 ConceptFormation（旧实例不可增量复用——
重复呈现会把差分边顶到 cap、聚类糊掉），幅度累计器清零后在**新通道面上
重分析全部自动对**（旧归因不混入新表面）。

## 量程扩展验收（世界中途展示比假设更大的范围）

设定：电压量程 [0,4.5] 对编码器从起始可见，但候选网格初始只到 3.0；
一阶段自然终止后扩展候选值 [3.9, 4.5]。对照：conceptUpdate=true vs false（冻结）。

**更新模式**（种子 1）：一阶段 72 实验、4 次形成（含周期刷新）；扩展后第 5/6 次形成
结晶出 **3.94 高压概念**；voltage 归因证据 31 → 45 对持续增长；扩展区探针
71.8%/88.9%，全网格 81.9%/96.1%。

**冻结对照**（种子 1）：形成历史恒为 1（概念层停滞 ✓ 符合预期）；但——
**感受野重叠使它没有失明**：3.9/4.5 落入 3.04 概念尾部而仍可解析，
voltage 归因证据 43 → 54 同样增长；扩展区 81.9%/97.2%、全网格 87.7%/98.3%
（高于更新模式——主因是冻结多做了 44 次实验（131 vs 99），覆盖差异而非机制胜负，
如实记录）。

## 结论与边界（如实）

- 机制验收达成：覆盖缺口触发 → 重形成 → 新区域结晶为概念 → R2 在新表面持续归因，
  全链路实机工作；周期刷新在无新结构时是安全空操作（第 2-4 次形成完全相同）。
- 概念层的"解释完整性"是更新模式的明确收益：冻结的 3.9/4.5 永远寄生在 3.04 概念里
  （扩展区内部的电压变化对 R2 不可见——本场景中扩展区亮度饱和无变化，不可测量，
  故不构成准确率差异）；重叠容忍意味着**相邻扩展天然可解析，致盲只在远域扩展出现**。
- 准确率对比受实验数混淆（终止时刻的轨迹随机性），两种模式不据此次数判胜负。
