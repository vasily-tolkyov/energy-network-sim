# Minecraft 对接设计（感知 → 学习 → 规划 → 执行）

**目标**：把我们的经验学习原型放进 Minecraft 自由探索，展示贴近人类的经验学习方式（无梯度下降、无课程表、从观察中自己长规则）。

**与他人方案的区别**：已有的 Jev+GPT 通关 Minecraft 是"梯度下降训练 + LLM 推理"路线。我们的路线：**规则全部由能量网络从经验中学**；Jev 只做感知接地与可行性判定（躯体层）。学习机制的可解释性（势阱、否决、计票纠错）是我们的核心差异。

## 链路

```
Minecraft 世界
  → 状态采集：mineflayer bot API（位置/血量/饥饿/周围方块/生物）+ 可选截图
  → 视觉前端（截图→文字描述，可选；状态文本可直接用）
  → Jev 语义解析（minecraft-spec.ts 的 MC_PERCEPTION）→ 条件帧
  → 能量网络：探索学习转移规律（如"黑夜+无遮蔽→受伤"）
  → 规划核心：多步目标链（如"活到白天并到达山顶"）
  → 执行映射（MC_EXECUTION）→ mineflayer 动作
```

## 分阶段验收（建议）

1. **mock 状态流**（本轮已做）：Minecraft 形状的离散世界 + 文字状态流，全链路离线验证。证据：`test/minecraft-mock.test.ts`。
2. **本地服务器小规模**：搭一个平坦世界服务器，mineflayer 接入，目标"黑夜存活"（学会躲入遮蔽/远离怪物的规律）。
3. **真实地形探索**：学会"岩浆危险""水可通行""高处跌落受伤"等规则并用于目标规划。

## 当前缺口（如实）

- 需要一台 Minecraft 服务器与 mineflayer 环境（本轮未做）。
- 视觉前端需要视觉模型端点（Jev 当前仅文本；截图链路 = 视觉模型 → 文字 → Jev）。
- 连续地形的状态离散化靠 MC_PERCEPTION 的粗粒度语义档——细粒度空间推理不在第一轮范围。
