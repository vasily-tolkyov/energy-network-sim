# 用二态能耗网络复现 R1/R2A/R2B/R3 预测原型：评估与实机结果

日期：2026-09-17。代码：`energy-network-sim/src/prototype/`，运行 `npm run proto`，日志 `runs/proto-v1.log`。

## 依据与边界

架构分工来自 `kairos-core-rebuild/docs/R1-R2A-R2B-R3-AND-ATTENTION.zh-CN.md`。本复现是**功能原型**：离散档位编码的小球碰墙课程，不是材料物理复刻。如实声明的简化：

- R2A/R2B 的比较（共性/差分/影响判定）实现为对 R1 神经元群体读出集合的函数操作，不宣称是神经机制（对应材料实现的"暂存+差分"功能位）；
- 结果通道档位互斥抑制 Γ 是结构先验（一通道不取两档），不是从经验学出的；
- 教师地面真理只用于课程生成与评分，不进学习核；同步信号只控制比较时机；
- 不涉及时序有向通道（已另行验证），本原型是静态模式选择。

## 四层 → 机制映射

| 层 | 实现 |
|---|---|
| R1 表层经验 | 每次经验 = 条件∪结果神经元共激活赫布绑定；基础耦合封顶 0.4（均匀 k_h，不随频次漂移）；轮末恢复静息，连接保留 |
| R2A 结果提取 | `compareOutcomes`：共同结果 ∩ 逐通道差分，变化标志与数值分离（1→0 仍是变化） |
| R2B 因素提取 | `extractInfluences`：变化候选 ∩ 结果变化 → 影响因素；影响幅度 m = 归一化 \|Δ结果\| 均值 |
| R3 规则记忆 | 侧重绑定 `k = k_h + η·G·m²`（§7.1 的 k_h(1+Gf²) 类比）；读出 = 查询钳制条件 + 结果通道候选集上局部退火（Γ 竞争单档） |

## 实机结果（3 种子 × 48 查询/种子）

| 配置 | 细粒度（反弹+速度档） | 粗粒度（反弹有无） |
|---|---|---|
| 完整模型 | **83.3%** | **100%** |
| 消融 G=0（断 R2B 侧重） | 34.0% | 52.8%（错过墙门控崩溃至 5.6%） |
| 消融 纯贪心读出（无退火竞争） | 0%（全歧义） | 0% |

结论：该架构在本原型规模上**展示了根据经验的预测能力**——未见颜色不丢规则适用性（文档 §7.1 场景，未见颜色查询粗粒度 100%）、控制变量提取的影响因素承载了门控（断侧重则门控崩溃）、退火竞争承载了读出分辨。残余失败集中在高速角（speed 最高档的反弹速度系统性偏低 1-2 档）——加性匹配的细粒度分辨率极限，如实保留。

## 过程中发现并修复的缺陷（全部有实机记录）

1. **Γ 偏移 bug**：抑制边写在 0 基地址上（落在颜色档而非结果档）——抑制形同虚设，全歧义。
2. **封顶 bug**：`strengthen` 的 cap 写成硬钳（`min(cap, cur+δ)` 会把已增强边压回 cap）——后教组把侧重边销毁。改为"只增不减、到顶不动"。
3. **读出雪崩**：淬火全网扫尾时对称 W 把结果活动反传回未查询条件档——读出场景淬火限制在候选集。
4. **查询学习污染**：响应模式学习首版无封顶，48 查询的增量盖过 24 次教学——改为小步长+同封顶。修复后查询学习仍有轻微自强化副作用（未见颜色 83%→67%），如实记录。

## 第二主题迁移测试（原型机制冻结）

`src/topics/plant-world.ts` + `runner-plant.ts`（`npm run proto:plant`，日志 `runs/proto-plant-v1.log`）。植物生长实验：光照×水量交互 + 肥料/温度加成 + 虫害门控 + 品种干扰；通道结构、结果函数、门控位置均不同于小球主题。机制代码与全部参数（θ=1.5、η=0.1、基础封顶 0.4、γ=3.0、G=3）未做任何改动。

| 配置 | 细粒度（存活+生长量档） | 粗粒度（存活） |
|---|---|---|
| 完整模型 | 76.6%（含查询学习）/ 84.4%（无查询学习） | 100%（虫害门控 100%） |
| 消融 G=0 | 25.0% | 55.7%（虫害门控 11.5%；无查询学习时 56%） |
| 消融 纯贪心读出 | 0%（全歧义） | 0% |

结论：机制与参数零改动迁移到结构不同的主题，预测能力复现——控制变量正确判别干扰因素（品种）与四类影响因素、幅度加权的门控（虫害 m=0.92 最大）成立、退火竞争读出仍不可或缺。残余失败与第一主题同型：低光照/低水量角落生长量档系统性偏高 1-2 档（加性匹配的细粒度极限）。查询学习在两个主题中都轻微有害（自强化错误预测），如实记录。

## 容量评估（`npm run exp:capacity`，日志 `runs/capacity-v1.log`）

**C2 资源侧（装配容量）**：N=8000（三张 N² 矩阵共 1.5GB）下 100/200/400 个 16 神经元势阱，检出率与 25% 线索捕获完成率均 100%、零误激活，单次捕获约 0.3s。资源远不是瓶颈。

**C1 规则容量（预测核心）**：合成规则域（两因素+干扰 → 8 档结果通道），两种真理结构 × E 个教学规则：

| E | mod-8 对抗性（taught） | 平滑可加（taught / heldout） |
|---|---|---|
| 8 | 87.5% | 50.0% / 20.5% |
| 16 | 62.5% | 56.3% / 30.2% |
| 32 | 35.9% | 60.9% / 50.0% |
| 48 | 19.8% | 56.3% / 56.3% |
| 64 | 12.5% | 56.3% / — |

- 容量瓶颈是**干扰**（结果通道竞争），不是资源：规则数增长时准确率按真理结构分化——对抗性（mod-8）结构不可加性分解，E=16 后跌破 60%，E=64 只剩 12.5%（≈ 随机基线 1/8），留出查询恒 0%（不可插值）；平滑可加结构 taught 稳定在 ~56% 不随 E 崩，heldout 随覆盖率升到 56%（插值有效）。
- G=0 断侧重在 mod-8 下直接 0%——竞争分辨完全依赖侧重。
- 结论：本机资源可承载的神经元规模（~10⁴）远超预测核心所需；概念容量由编码结构与规则可加性决定，按此编码约为**每 8 档结果通道数十条规则**（对抗结构）到**平滑结构下对 E 不敏感的稳定中等准确率**。提升容量需要结构性改动（群体编码、分层背景门控、更多结果通道分离），不是加内存。

## 三层神经网络版（R1/R2/R3 各自独立成网，`src/layers/`，`npm run exp:layers`）

按"每层一组神经网络"的架构重组：R1 网存每次实验的"条件阱→结果阱"势阱对（含条件→结果有向通道，链式生成基础）；R2A 结果比较（结果集仅 2 神经元，重合场分层不适用，保留读出层操作，如实记录）；R2B 在独立工作网中让两次实验的条件模式成阱，用**高阈值重合场分层**神经化筛出共同项与差分候选（|交集| > (|阱|+1)/2 时分层窗口存在），影响因素由双源 AND 神经元点火（差分 × R2A 结果变化，θ 设单源不越阈）；R3 独立网绑定背景+因素+结果并做退火读出预测。

**实机对照（同一小球课程与查询集）**：三层版细粒度 **83.3%**、粗粒度 **100%**、错过墙门控 **100%**——与单网原型逐点一致；G=0 消融同样退化到 34.0%/52.8%。R2B 差分通道判别全对（颜色/阻尼/方向无影响，速度/刚度/碰墙有影响），且自动识别出课程中刚度组第二对 (0↔1) 结果档恰好相同的退化比较（如实判为无影响）。意义：R2B 的"共同项筛选 + 差分"从读出层函数运算升级为网络动力学——评估文档此前"比较操作尚未神经化"的边界在 R2B 侧闭合。

过程中的关键发现：①重合场分层要求交集自维持大于单阱自维持（|交集| > (|阱|+1)/2），否则无阈值窗口；②AND 判定必须限制读出候选集，否则共同项势阱在 settle 中自点燃造成假影响；③影响边权按差分神经元计数设计（单通道变化恒 2 个，0.5×2+1.0=2.0 恰越阈）。

## 群体编码 + 规则核版（`src/pop/`，`npm run exp:pop`——runs/pop-v1.log）

按"概念只存在于共现形成的势阱"重构表征层：每档 = 4 神经元群体（不再一档一神经元）；每条经验 = 私有 4 神经元规则核；结构 条件群体（共享）→ 规则核（私有，核间 Γ 互斥）→ 结果群体（共享）；影响因素侧重加在"因素群体→核"边上；预测 = 候选集（全部核 ∪ 结果群体）上局部退火选出获胜核。

**规模与激活**：球实验网络 620 神经元（条件 84 + 结果 24 + 核区 512，24 规则实占 96）；每输入激活 ≈ 24 钳制 + 4 获胜核 + 8 结果 ≈ 36。容量版 896 神经元（192 核区）。

**小球端到端（3 种子均值）**：完整 细粒度 84.0% / 粗粒度 100% / 门控 100%（单网 83.3% 同水平）；无查询学习 88.2%。**G=0 消融 82.6%/门控 91.7%**——单网版断侧重门控崩到 5.6%，核版核竞争自身承载匹配，消融性质改变（如实记录：侧重在核版中不再是门控的唯一来源）。

**容量重跑（E 规则数）**：mod-8 taught 68.8%→**47.7%@E=64**（单网 12.5%，约 4 倍），heldout 出现非零插值（12–19%）；平滑结构 taught 100%@E=8、64.1%@E=64。残余退化主因：共享 2/3 条件的近邻核与精确核场强接近，竞争随机化——如实保留。

## 侧重否决版（veto）

在群体编码+规则核之上加两个改动：①**侧重否决**——bindInfluence 时，影响因素通道的每个已观察替代档 → 核写分级抑制边（γ_veto×群体 > 单通道最大支持）：精确匹配核恒胜任何含一处影响因素不匹配的核，全无精确匹配时同罚级核按支持竞争（泛化兜底不死）；②**互斥从经验学习**——结果通道的档位抑制不再预置，教师每对换一对值就学一条。③顺带修正：教学绑定改为"条件↔核、核↔结果"两段——直连条件↔结果是绕开核仲裁的短路（曾致混答；另试过封顶 0.1 的弱直连做插值偏置，规则一多短路复现，已回滚）。

**R2A 已神经化**（`src/pop/r2pop.ts`）：对完整经验模式（条件∪结果，8 群体=32 神经元）做一次重合场分层差分（θHigh=27，窗口 24.8–30.4），R2B 读条件侧、R2A 读结果侧——两分支共享同一次动力学（对应文档"互相配合的分支，不是两级流水线"）。双源 AND 边权按群体尺寸标定（0.5/popSize，防群体规模破坏阈值语义）；结果档差按（通道，档）去重。退化对（刚度 0↔1 结果档相同）被动力学自动判为无变化。此前"R2A 结果比较是读出层操作"的遗留边界闭合；幅度口径与读出层统一（按全部结果通道数取平均）。端到端成绩与读出层版逐点一致。

**容量（runs/pop-v1.log）**：mod-8 与平滑两种结构下 **taught 全部 E 档 = 100%**（E=64 亦 100%，此前 47.7%/12.5%）——精确检索问题被否决制解决；heldout 随覆盖率升到 **93.8%**（E=48，分级否决的兜底竞争在高覆盖时插值极佳；E=64 行 heldout=0 是定义使然）。

**小球端到端**：粗粒度 100%、错过墙门控 100%（无查询学习时细粒度 68.1%）——去除直连短路后未见组合插值变弱（直连时代 58%→25% 量级），这是换容量的真实代价，如实记录。G=0 消融现在同时断否决（否决边随 boost 写），门控回到 5.6%——否决正是门控的机制本身。

## 抑制池 WTA 版（当前版本）

在 veto 版之上把概念自形成版验证过的**前馈抑制池**移植到 PopRuleMemory 核区：2 个池神经元，核→池分级招募（0.3/0.15：单核 4×0.3=1.2<θ 沉睡，≥2 核 8×0.3=2.4>θ 点燃），池→核 DI 前馈抑制（γ_pool=4.5，按本模块核支持标定：压灭 1-失配核的 +2 净场、持证精确核 8-12 净场存活）。动机：两两互斥 Γ 的共激活代价固定、不随联盟规模增长（化学主题实机抓到双核满激活共存），池让代价随联盟规模上涨。

**移植中实测并修复的两个动力学问题**：①池版初期淬火弛豫振荡（池压灭双核→池熄火→1-失配核借强支持复燃→池再点燃）使单次预测均时从 ~0.1s 劣化到 1.2s（最慢 4s）——根因是核间 Γ_core=1.5 压不住 +2~+8 净场的复燃，改为 3.0（与 field-memory 同值，联盟代价 4×3=12 > 任何 1-失配核净场）后单核态成为稳定不动点，均时回落到 ~0.15s；②振荡消除后退火在逐查询走查中稳定给出**单核胜出**。

**小球端到端（runs/pop-v1.log）**：无查询学习 **细粒度 86.1% / 粗粒度 100% / 门控 100%**（veto 版为 68.1%——共存核对结果群体投票的模糊被 WTA 消除，细粒度 +18 点）；含查询学习 67.4%/87.5%/75.0%；G=0 55.6%/73.6%/47.2%。**容量**：两结构 taught 全部 E 档 ≈100%（mod-8 E=48 实测 99.0%，唯一非满分档，如实记录）、heldout 与 veto 版逐点一致（平滑 E=48 仍 93.8%）——容量战果无损。

**查询学习在 WTA 下的性质反转（如实记录）**：单核胜出把结果交给唯一胜核——精确签名的查询核必赢自己的签名，于是响应学习把**任何**预测（对或错）干净地固化。基线准确率高时它自我巩固（化学主题无查询 64.6%→含查询 79.2%），基线错误率不可忽略时它固化错误（小球 86.1%→67.4%）。veto 版的多核共存曾模糊这一效应（错核常被教过核投票压过）。结论：响应学习的价值取决于基线准确率，无观察反馈时错误记忆无法自愈——需要时应以观察回写（learnFromObservation，封顶 0.6）纠错，或按置信门控查询学习（未实现）。

**响应学习两处缺陷修复（化学主题独立测试抓获，详见 `docs/EVALUATION-CHEM-INDEPENDENT.zh-CN.md`）**：①learnFromQuery 新核未"持证上岗"（无侧重/否决边，绕开否决体系引发错误自我强化级联，化学 v2 seen-combo 曾崩至 3.7%）；②learnFromQuery 把条件∪核∪结果放进同一次 hebbianLearn，写下本架构明令禁止的条件→结果直连边与结果通道接力边（实机抓到精确核满激活却读出错误结果——输入群体绕开核直接驱动结果群体）。修复后化学独立测试（runs/chem-pop-v1.log）：**seen-combo 100%、no-reaction 100%（v2 课程）、总细粒度 79.2% / 粗粒度 97.4%**。

## 注意力机制接入（`src/pop/attention/`，`npm run exp:attention`，runs/attention-v1.log）

历史版注意力控制器/监测器（kairos-core-rebuild 仓库历史文件）已移植并接入响应模式循环：控制器原样保留评分/突变抢占/迟滞+持续 tick/近似平局 softmax（PRNG 换可复现种子）；监测器按三条硬规矩改造——三类比对分开（符合/偏差/未知）、迟到预测不配对、注意力只调度不碰动力学。响应模式学习修正为**写观察不写预测**，且观察证据封顶 0.6 > 自写猜测 0.4（纠错可压旧错）；新核"持证上岗"（按侧重并集补正/否决边）。

**世界流实验（3 球 70 tick，含未见组合与门控翻转）**：预训练基线 75%（结果按通道绑定修正同时抬升了基线）；门控模式 75→67→**75**（t20 一次写入引起瞬时抖动后自愈，终点 = 基线、含 4 条语义正确的通知）；闭眼写预测模式崩到 **8%**（自强化错误的直接证据）；不写模式稳定 75%。

过程中修复的结构性缺陷：两段绑定曾把"结果↔结果"边也写进网络，被驱动的结果档经 reb↔rs 边接力驱动其它档，再叠加互斥覆盖缺口（rs2↔rs3 从未被换对观察），形成跨档同盟压过正确档——结果绑定改为**按通道分别绑定到核**后泄漏消失（基线 58.3%→75% 的直接原因）。

如实标注：goalRelevance/novelty/changeDerivative 按历史实际调用默认 0；focusHeldTicks 疲劳与近似平局规则沿用历史但未在新模型验证；G=0 断侧重时门控退化为 ~58%（否决是门控的机制，但不是唯一贡献）。

## 连续输入概念自形成（`src/pop/concept/`，`npm run exp:concept`，runs/concept-formation-v1.log）

按"维度保留、值自形成"形态实现：S0 非承诺高斯感受野编码（每维 40，相邻重叠，相似性保持有测试）→ 共现成阱 + 换对互斥 → 按维度权重聚类出自形成值概念。形成实测：速度维 {2.00(20成员合并低值区), 6.50(9)}、墙刚度维 {0.38, 1.09, 2.63}、碰墙维 {0.05, 0.95}——**密集覆盖的低值区合并为粗概念、稀疏处自动分离**，与文档"大范围共性及其细分结构应来自经验"的粗阶段一致（如实记录：合并区 IoU 低、分离区 IoU 1.0）。

**WTA 与前馈抑制（基质升级，全部有实机记录）**：
1. 多核联盟困住（同步点火 + 对称抑制无中间态）→ 先试对称 Γ 全局抑制池：**池被自己的对称抑制边掐死**（基质约束，记录在案）；

## 注意力机制去人工化（B 段，src/pop/attention/，runs/neural-attention-v1.log）

**公式替换表（实机结果）**：
- 三类判定（原 comparePublicPrediction）→ **捕获检验**：观察与条件同钳，由势阱归属给出（预测核被捕获=符合；他核被捕获=偏差；无核捕获=未知）。与公式容差版同帧对照**一致率 83.3%**；唯一分歧（未形成区 C.speed=4.5）是"未知"两种定义的语义差别：公式版=无置信预测，捕获版=有势阱认领（更结构性）；
- 评分加权和 → **失配场**（mismatchField：预测核对自身答案场的覆盖 − 对观察场的覆盖，纯边权读出）；
- holdBias/迟滞边距/持续 tick → **惯性边 + 失配随帧衰减**（连接性质；实测持焦/换焦正确）；
- 突变阈值 → 失配场越过点火阈值直接点燃挑战核（无参数）；
- 焦点竞争 → **WTA 退火**（marker 互抑）。

**端到端焦点序列（全部落在事件对象上）**：t1 ∅→A；t20 A→B（门控翻转）；t30 B→A（未见组合）；t40 A→C（未形成区）；t55 C→B（门控恢复）。门控学习后准确率 80%（不退化）。公式控制器基线（历史版）：5 切换 5 抢占，事件覆盖一致。

**过程中的三个实现修正**：失配场必须对预测核测量（捕获核吻合观察恒为 0）；失配边必须绝对重写+随帧清零（否则持焦锁死）；焦点比较必须取 select 前的旧焦点（否则永不打印切换）。测试 test/neural-attention.test.ts 4 项全绿。
