# PLAN-009：多步目标链规划实测

基线 `33f8b6a`；2026-09-20，本机 Node.js 24.14.0。实现分为路径世界提交 `6c02097`、有序链与执行监控提交 `81768c5`、评估与文档提交。精确源码 SHA256 和证据校验见 `runs/plan-source-manifest.json`。原始输入计划归档为 [PLAN-009](PLAN-009-goal-chain-planning.zh-CN.md)。

**结论：预先规定的 P1–P8 在种子 1/2/3 均通过；P9 全量测试 198/198，零失败、零跳过。** 神经网络学习单步转移，程序化控制负责动作枚举、正向展开、回退、循环检查和重规划。没有把路径公式、BFS 答案、观察转移表或回归器用于规划预测。这些证据仅覆盖两个有限离散世界，不证明开放世界、多层目标或长期自主能力。

## 实现与固定协议

- 每个模型一份 `FieldRuleMemory`，条件为状态与动作，结果为下一状态。沿用每维 40 个感受野、默认核心大小和全部学习/求解阈值。世界 A 网络 N=186，世界 B N=162；规则容量分别为 16、10。
- 收集器在允许复位的实验台上，按已知状态/动作字母表做种子打乱的均衡课程。A 为 16 种查询各观察 4 次，共 64 次；B 为 10 种查询各 4 次，共 40 次。每个回答调用一次已有 `learnFromObservation`，默认 repeats=2。停止原因是 `budget-exhausted`。这是语料式自主采样，**不是只能从前一物理位置行动的具身探索**，也不是 `quorum-met` 完备性证明。
- 观察后复用已有 R2 神经差分，比较只差一个条件维的真实观察对。A 64 对、B 25 对，识别出各自状态维与动作维；没有把因素名称当答案预填。对每条已观察查询执行一次 `bindInfluence`，**gain=0、veto=on、默认 Γ**。只是复用已有独立否决机制，没有新机制消融，也没有增加兴奋幅度来凑分。
- 规划器只有只读预测接口。条件“见过”只存签名集合，不存转移答案。下一状态始终来自 `FieldRuleMemory.predict`。完整同支持区优先解码，否则要求只有一个相容的离散符号；多个候选、任何输出缺失或歧义都报告未探明，不强制四舍五入。
- 动作按 PLAN-009 的四层优先级及编号排序。使用正向深度优先展开与回退；没有目标距离评分、反向推断或 BFS。循环检查针对当前路径，缓存仅在一次计划内存在。回退也共用总预测预算：A 深度 14、最多 28 次 predict；B 深度 8、最多 16 次 predict。B 的“直径 4”指最大有限最短路径，反向状态对本来不可达。
- `no-quiet-candidate` 排除该动作；未知结果留下 frontier；有值的非收敛预测仍可入链。超深度、超预算、未探明、已学模型中没有路线分别报告。`no-known-route` 不等于对真实未知世界作不可达证明。
- 执行使用冻结的 `ForecastSnapshot` 值与代际，先联合捕获、后登记真实观察。`cap.class !== within-envelope` 必须重规划。另检查实际离散状态是否仍等于计划的下一输入，避免编码相容但离散状态已变时沿用失效链；这不改变共享的编码相容关系。rollout 从不写入观察或假设。
- 执行总预算 A=14、B=8 次。每次重规划仍有上述固定预算，执行总步数限制重规划次数。对照模型从相同种子的训练课程重新初始化，测试间不串用已纠错记忆。

## 世界 A：到达率、长度和随机对照

每种子将全部 **56 个非平凡有向起终点对**打乱后执行；start=goal 的零步行为另由永久测试覆盖。下面均为实测，无调参回锁。

| 种子 | 原始计划执行到达 | 带监控执行到达 | 随机动作到达（最多 14 步） | 原始计划步数/BFS 中位数 | 监控重规划次数 |
|---|---:|---:|---:|---:|---:|
| 1 | 56/56，100% | 56/56，100% | 29/56，51.8% | 1.0 | 0 |
| 2 | 55/56，98.2% | 56/56，100% | 31/56，55.4% | 1.0 | 1 |
| 3 | 56/56，100% | 56/56，100% | 32/56，57.1% | 1.0 | 0 |

原始计划到达 **167/168**；带监控 **168/168**；随机 **92/168，54.8%**。原始计划全部样本步数比的 min/median/p90/max：种子 1、3 为 1/1/1/1，种子 2 为 1/1/1/2。只看成功样本时三种子全为 1/1/1/1；失败并未从原始分布或到达率分母删除。监控执行的种子 2 最大比值为 3，其余仍为 1；三种子中位数均为 1。

每次原始规划 predict 次数 min/median/p90/max 为 **2/8/14/14**，均值 8；每种子 448 次。这个离散路径世界的成功路线恰好最短，不构成对任意模型或图的最短路径保证。BFS 只在 `src/topics/plan-evaluation.ts` 的实验台评分函数中出现，规划模块没有导入它。

公平预算口径是相同的实验台训练机会和在线动作上限；随机策略不利用训练回答，也不消耗神经预测计算。不是计算量相同的算法比较，亦不是未观察转移的泛化实验。

### 保留的失败

正式种子 2，start=1、goal=2，退火 seed=2002403 把 `(pos=0, move=1)` 预测为 nextPos=2。按动作编号先展开左路，原链成为 `1→0→2`，实际执行为 `1→0→1`，未到达。该预测是 **fixed-point**，不是不收敛；稳定状态不保证答案正确。监控在第二步得到 `prediction-violation`，从实际 pos=1 重规划，追加向右一步抵达目标，增量 4 次 predict。完整值、核编号、代际、账本与观察见 `runs/plan-2.json` 的 `failures.openLoopPath` 和 `worldA.monitored`。

开发证据同样保留：

1. `runs/plan-development/raw-ranges.json`：只有观察、没有 R2 否决时，固定探针 16 个转移错 6 个。现有感受野/核竞争允许邻近经验干扰；本轮补全训练流程，没有改动预测核心。
2. `r2-veto.json`：同一探针加入 R2 识别的因素否决后 16/16 读回。没有扫描增益或否决阈值。
3. `path-open-loop.json`：另一组固定读出种子穷举 64 对时 63/64 到达，失败为 0→7 实际结束在 6。最初新增自测误要求 100%，失败日志 `path-test.log` 原样保留；正式断言按输入计划预先规定的 P1≥90%、P2≤1.5 编写，没有改动用户阈值或既有回归断言。

## 世界 B：顺序、单向门与扰动

三个种子均实测：

| 案例 | 监控执行 | 重规划 predict 增量 | 无重规划对照 |
|---|---|---:|---|
| 正常 A→E | A→B→C→D→E；顺序正确 3/3 | 0 | 非扰动案例不作此消融 |
| C→D 关闭 | 检出失配，观察写回，从 C 重规划；`no-known-route`，停在 C；3/3 | 每次 2 | 原链继续执行到底，停 C，0/3 到达 E |
| 到 B 时被置于 D | 检出失配，从 D 重规划到 E；3/3 | 每次 2 | 原链剩余前进行为也到 E，3/3 成功 |

正常顺序正确率 100%；全部输出链没有 D→C 步，显式 D→C 查询均 `no-known-route`。关闭后的重规划不再输出 C→D 假链。关门的监控执行 3 步、无重规划 4 步；位移案例监控执行 2 步、无重规划 4 步。

**不能从这个实验宣称扰动下到达率提高**：两种注入合并，无重规划实际目标失败率每种子都是 1/2；关门后目标客观不可达，安全停下才是验收目标。状态扰动的无重规划对照也能到达吸收态 E；监控的证据是发现偏离、从实际 D 建立新链并减少动作。正式 JSON 同时保存 reached 与 protocolSuccess，不把二者混为一谈。

B 的随机动作基线（同为最多 8 步，56 次/种子）分别 37/56、30/56、42/56 到达，即 66.1%、53.6%、75.0%。这是一个仅有前进/停留的简单链，随机策略也有相当成功率。

位移注入作为真实观察送入记忆后，会暂时被登记为 A 的动作导致 D。本轮没有实现外因识别；每个案例重置模型，不能把本实验证据扩大为能区分外力和内生转移的因果学习。

## 动力学、账本和隔离

| 种子 | 全部 predict 调用 | 非收敛 / 任一输出拒答 / no-quiet | 账本失配 | predict 平均毫秒 |
|---|---:|---|---:|---:|
| 1 | 1132 | 0 / 0 / 0 | 0 | 19.82 |
| 2 | 1136 | 0 / 0 / 0 | 0 | 20.28 |
| 3 | 1132 | 0 / 0 / 0 | 0 | 20.42 |

共 **3400 次预测**，每条 JSON 记录均有 `converged`、`terminationReason`、冻结值/代际和能量审计。全部 fixed-point，所选链步的固定点比例也均 100%；因此本轮实测**没有**证明非收敛链的实用成功率，该接口政策仅有契约测试覆盖。任一输出拒答率与未知离散解码率也为 0。捕获自身状态另在执行记录中保存。

审计同步旁观现有 `settleAnnealed` 调用，参数原样传递并验证三项静息/候选/翻转预算约束；在 finally 恢复方法。检查 trace 尾值、返回 energy、独立 θ/W/Γ 重算值，DI 不参与。容许浮点误差 1e-7；最大实际差 **5.862e-14**，失配 0。它检查返回状态账本，不声称对每一次内部翻转逐点重演。

冻结规划前后，A 每种子 16/16 确认查询值、歧义和状态读回一致；B 每个独立场景 10/10 一致，共 150/150。全部 W/Γ/D/DI 矩阵与注册证据的 SHA256 一致。这个隔离结论只说明只读 rollout 不改学习状态：它会更新暂态激活与被动诊断计数；本轮没有模拟写入通道，也没有验证“写入式假设不会污染经验”。

最终三种子完整实验耗时约 24.16、24.42、24.45 秒。早期探针含 JIT 启动峰值，正式均时符合计划几十毫秒量级；候选域约束没有遗漏。耗时是本机复现记录，不是硬件能效结论。
