# energy-network-sim

能耗极小化神经元网络模拟器。二元神经元（静息/激活）+ 赫布加强连接 + 势阱标签读出。

## 要求 → 机制映射

| # | 要求 | 机制 |
|---|------|------|
| 1 | 静息不耗能 | `runStep` 中 0→0 不计费；`energy(全静息) = 0` |
| 2 | 静息→激活耗能 Ea | `runStep` 对 0→1 一次性记 Ea |
| 3 | 维持激活耗能 Em | `runStep` 对 1→1 每步记 Em |
| 4 | Ea > Em | 构造器强制校验，否则抛错；并使启动阈值高于维持阈值（迟滞） |
| 5 | 普通连接组网，输入只激活一部分 | `settle(input)` 钳制输入神经元，其余按局部场决定是否招募 |
| 6 | 赫布加强连接，强度越大能耗越低 | `hebbianLearn` 共激活增强；`E(s) = (Ea+Em)·Σs_i − ΣW_ij·s_i·s_j` 中强连接压低总能耗 |
| 7 | 输入决定必须激活谁，最低总能耗决定模式 | `settle` 在输入钳制约束下收敛到 E 极小模式 |
| 8 | 不相邻极大值的 0.8 邻域 = 势阱，赋标签 | `detectWells`：局部极大边 → 贪心不相邻选取 → 0.8·峰值邻域 BFS；`ReadoutModule.labelWell / autoLabel` |
| 9 | 读出被激活势阱的标签 | `ReadoutModule.identify(activeSet)`：成员激活率 ≥ τ 判激活，按率降序输出标签 |
| 10 | 极小能耗由相互作用规律保证，不枚举 | `settle` 只执行局部翻转规律（ΔE<0 才翻转）；W 对称 ⇒ E 严格单调下降且有下界 ⇒ 有限步收敛。如同连通器不必比较全部液面配置即达最低重力势能。`settleAnnealed` 在此基础上加候选集内退火（见下） |

## 局部退火（`settleAnnealed`）

贪心语义的补充：极小化搜索域 = 候选集 C = 输入 ∪ 被输入触及的势阱。单一温度曲线：从静息+钳制直接 Metropolis 退火（带最优状态记忆），只翻越 C 内的协同势垒（单翻上坡、联合下坡），最后以 T=0 贪心扫描淬火收尾——贪心不是独立相，只是这条曲线的 T=0 端点。相同种子完全可复现。贪心 `settle` 仍是默认响应路径；退火用于需要精确"C 内能耗极小"的场合。

如实边界（第三方评审后修订）：①C 外神经元的结构性冻结只在淬火限制在候选集（`quenchCandidatesOnly: true`，全部预测路径都如此调用）时成立；默认的全网淬火会招募 C 外被场强直接推过阈值的神经元（无势垒直达）。②有限温度层数×扫描次数的退火是**有限预算近似搜索**：它返回 C 内的局部固定点（收敛时无残余可翻转），不承诺命中 C 内全局最小（有 12 神经元的反例实例保留在测试集）。③引入 DI 前馈抑制（非平衡驱动）后，动力学可弛豫振荡——账本只记保守能量（与 `energy()` 逐点一致）、DI 做功独立记为 `driveWork`、返回态如实带 `converged`/`terminationReason`/`residualFlips`，带池电路的回退只在驱动静息态中选（`fallbackQuietOnly`）。

## 资源复杂度

每个 EnergyNetwork 固定持有 4 个 N×N Float64 矩阵（W/D/Γ/DI），约 32·N² 字节：N=2000 ≈ 128MB，N=8000 ≈ 2GiB。稀疏激活不让矩阵本身变稀疏。局部场读出为整行扫描 O(N)；探索的配对 O(E²·d)、概念重形成为全量重放。这些是工程规模边界，不是机制声明。

## 有向通道与噪声转移（`sequence.ts`）

对称 W 承载关联与势阱（共激活学习）；有向 D 承载势阱间的转移通道（时序学习 `learnSequence`：前模式→后模式，单向）。两种机制分离，D 不参与 settle 的能量函数。`runTransitions` 在噪声浴（Metropolis，温度 T）中演化：有向驱动 β·g 把后继势阱的势垒压低但不归零，第一下点火由噪声完成，随后级联下坡补全；驻留疲劳（维持能耗随激活积累 κ、静息时按 κ_r 缓慢恢复）让旧势阱崩塌，活动沿有向通道迁移，形成 A→B→C 行波，最终归于静息。对照：T=0 无人点火；β=0 单点噪声点火无法级联；κ=0 新旧势阱共存而非转移。演示：`npm run demo:seq`。

## 大规模实机结果（`experiment-scale.ts`，日志 `runs/scale-v1.log`）

N=2000、16 神经元/势阱、θ=1.5、T=0.12、d=0.15、κ=0.7/κ_r=0.15：

- S1 容量：20/50/100 个势阱，检出率全部 100%，25% 线索捕获完成率 100%、零误激活；
- S2 链式生成：10 条不相交 5 节链 × 3 种子，逐棒交接 100%，完整链 30/30，事件序列零幻影；
- S3 分支：共享起点的等强双通道 + 抑制竞争（`learnBranches`，候选后继间 γ 抑制边）——每次运行互斥地只推进一条通道（共存 0/12），胜负按概率分配（12 种子 8:4；玩具规模 40 种子等强恰 20:20，偏置 0.55/0.40 时 36:4）。无抑制时 12/12 双点燃；互斥选择 = "小球只进一个槽"；
- S4 对照：T=0、β=0 均零转移。

规模化发现的两个现象及对策（已固定在参数里）：① 簇大到 16 时"双重点火"即下坡，热噪声会以每运行约 1 个的速率自燃无关势阱——降温到 T=0.12 后压到约 0.02/运行；② 大簇成员异步疲劳死亡会被下坡再点火回填、形成不死的周转亚稳态——引入慢恢复疲劳（κ_r=0.15）后崩塌干净。

## R1/R2A/R2B/R3 预测原型（`src/prototype/`）

在二态能耗网络上复现四层预测链：R1 经验共激活绑定（基础耦合封顶，轮末静息）→ R2A/R2B 控制变量比较（变化标志与数值分离，影响幅度 m）→ R3 侧重绑定（η·G·m²）+ 结果通道 Γ 互斥竞争 + 局部退火读出。实机：细粒度预测 83.3%、粗粒度反弹 100%；断侧重（G=0）门控崩溃至 5.6%；纯贪心读出全歧义。第二主题（植物生长，机制与参数零改动迁移）：细粒度 84.4%、粗粒度 100%、虫害门控 100%。映射、边界与缺陷记录见 `docs/EVALUATION-PROTO-REPRODUCTION.zh-CN.md`。运行：`npm run proto` / `npm run proto:plant` / `npm run demo:walk`（走查演示）。

容量评估（`npm run exp:capacity`）：资源侧 N=8000 下 400 势阱检出/捕获 100%（约 0.3s/次）——资源不是瓶颈；规则侧容量由干扰决定：对抗性 mod-8 结构 E=8→87.5%、E=64→12.5%（≈随机），平滑可加结构稳定 ~56% 且可插值（heldout 56%）。

三层架构（`npm run exp:layers`，`src/layers/`）：R1/R2/R3 各自独立成网——R1 存"条件阱→结果阱"势阱对（含有向通道）；R2A 结果比较；R2B 神经差分（重合场分层筛共同项 + 双源 AND 判影响）；R3 规则绑定与预测。端到端与单网原型逐点一致：细粒度 83.3%、粗粒度 100%、门控 100%；R2B 比较由此神经化（原读出层函数运算的遗留边界已闭合）。

群体编码+规则核+侧重否决+抑制池 WTA（`npm run exp:pop`，`src/pop/`）：概念全部改由共现势阱承载——每档 4 神经元群体、每条经验私有 4 神经元规则核；影响因素通道的替代档对核写分级否决边（精确匹配恒胜，无精确时按支持兜底）；互斥从换对学习（不再预置）；教学为"条件↔核、核↔结果"两段绑定（去除直连短路）；核区前馈抑制池（分级招募、DI 非平衡驱动）逼出单核胜出，核间 Γ=3.0 使单核态稳定。**容量：两种真理结构下 taught 全部 E 档 = 100%**（E=64 亦 100%），heldout 随覆盖率升到 93.8%；小球端到端粗粒度/门控 100%，无查询学习细粒度 86.1%（池消除多核投票模糊，较 veto 版 +18 点；含查询学习 67.4%——WTA 下响应学习固化基线错误的性质反转，评估文档有录）。网络 622 神经元、每输入激活约 32、单次预测约 0.15s。

第三主题独立测试（`npm run exp:chem`，`src/topics/chem-world.ts` + `runner-chem-pop.ts`）：化学反应实验（析取门控"催化剂 OR 高温" + 可加合成速率 + 容器干扰因素），机制零改动复用预测核心。R2 正确排除干扰、幅度序与真理一致；均衡课程下 **seen-combo 100%、无反应门控 100%、总细粒度 79.7% / 粗粒度 97.4%**。测试过程中抓获并修复响应学习两处缺陷（无证核自我强化级联、直连/接力泄漏），详见 `docs/EVALUATION-CHEM-INDEPENDENT.zh-CN.md`。另发现教师侧规律：析取门控的关闭分支必须多背景演示（稀疏覆盖 56.9% → 均衡覆盖 100%），与小球 miss-wall 同理。

无教师自主探索（`npm run exp:explore`，`src/pop/explore/` + `src/topics/lab-world.ts`）：第四主题电路实验台（合取门控 + 拮抗因素 + 干扰项，真值结构与前三者全不同），零规则起步、无课程无人工选择。闭环：无知场（无核覆盖或维度取值从未被观察，纯边权读出）+ 意外场（偏差邻域增压衰减）→ 候选干预 WTA 择选（NeuralFocusNet 复用）→ 上台实验（计成本）→ 每次实验都写观察 → Hamming-1 自动成对 → R2 → 侧重否决 → 规则核；无知场全消 + 16 连验证无偏差 + 各维两端极值被操纵过则终止（终止原因结构化上报）。控制变量法躯体化为动作空间（候选干预 = Hamming-1 前沿，"同时变两维"的动作不存在）。**3 种子验收全达标**：均值 91 次实验（穷举 288 的 32%）、R2 因素发现 4/4 全对且干扰项全缺席、严格联合 94.3%/粗粒度 99.4%（口径：全部未观察桶 + 常数基线 + 拒答率，第三方评审后修订）。详见 `docs/EVALUATION-EXPLORE-LAB.zh-CN.md` 与 `docs/EVALUATION-REVIEW-REMEDIATION.zh-CN.md`。统一视角：教师带领 = 只需观察的探索特例，学习管线同一套，效率差来自教师知道真值。

阶段 B 连续版（`npm run exp:explore-cont`，`explorer-continuous.ts` + `lab-continuous-world.ts`）：同一因果结构改为全连续值——分档不再给定，值概念由系统**自己的实验史**结晶（B0 语料相 → 语料充分性门 → 概念形成间歇期 → B2 全机器相）。**3 种子验收**：均值 117 次实验（27% 穷举 432）、因素 4/4 ×3、门控两侧经验区各自结晶为独立概念（如实边界：候选点恰好含 0.5 时阈值不可唯一定位——"经验区形成概念" ≠ "识别精确物理门限"，见可辨识性分析）、gate-off 97.6-100%、总细粒度 84.2%/粗粒度 97.5%。A/B 对照：自形成表征的代价是实验数 +48%，粗粒度不降反升。过程修复三处：field-memory 观察核不可见（严重，空白起步纯观察学习曾全部读空）、predict 长尾爬降（同 PopRuleMemory 疗法）、语料充分性缺失（零变异维只成 1 概念 → R2 漏判级联崩溃——"每维都变过"是控制变量法的另一半，已躯体化）。

概念更新（`npm run exp:explore-ext`，"细分后至"闭合）：间歇期后概念不再冻结——覆盖缺口（新值解析不到任何概念）或周期刷新（每 25 实验）触发全量重放到全新 ConceptFormation，幅度累计器清零后在新通道面上重分析全部自动对；规则核绑定感受野而非概念，概念演化零损伤已学规则。量程扩展验收（电压候选中途扩到 [3.9,4.5]）：更新模式第 5/6 次形成结晶出 3.94 高压概念、归因证据持续增长；冻结对照概念层停滞，但感受野重叠使相邻扩展仍可解析（致盲只在远域扩展出现，边界如实记录）。

注意力机制（`npm run exp:attention`，`src/pop/attention/`）：历史注意力控制器/监测器移植接入响应模式——三类比对（符合/偏差/未知）+ 时序纪律 + 门控写观察（封顶 0.6 压自写猜测 0.4）。世界流实验：门控学习终点 = 基线且抖动自愈，闭眼写预测崩到 8%。R2A 已神经化（全模式重合场分层，R2A/R2B 同一次动力学双侧读出）。

注意力机制去人工化（npm run 见 src/pop/attention/）：手写公式逐项由动力学替代并实机验证——三类判定改捕获检验（势阱归属给出符合/偏差/未知，与公式版一致率 83.3%）、评分和改失配场（覆盖差纯边权读出）、迟滞改惯性边+失配随帧衰减、突变改失配点火、焦点竞争改 WTA 退火（诚实框架：神经候选筛选 + 读出层择优，等强平局由 `lastSelectionTied` 如实上报，不静默兜底）。端到端焦点序列全部落在事件对象上（∅→A→B→A→C→B），门控学习后准确率 90% 不退化。

连续输入概念自形成（`npm run exp:concept`，`src/pop/concept/`）：连续传感 → 非承诺感受野编码 → 共现成阱 → 按维度聚类出自形成值概念（密集区合并为粗概念、稀疏处自动分离，与"共性先行、细分后至"一致）。下游全管线跑通：场级 R2 差分（影响因素全对）、场级规则核与否决、连续真值容差评分——**粗粒度 96.7%、细粒度 85.0%、错过墙门控 96.7%**、如实歧义 1/60。基质升级：有向抑制矩阵 DI 实现前馈抑制池 WTA（静态能量耦合必对称，前馈抑制只能作非平衡驱动场——供能电路），单核时池沉睡、多核时点燃压制；幻影块（相邻结果场自维持链）已用星型绑定清除。**关键结论：门控 40%→96.7% 的修复来自课程均衡（多背景 miss 覆盖）而非机制——门控失败曾是经验覆盖问题**。

## 涌现与先验的边界（第三方评审后明确列出）

"全部由能耗规律涌现"不作为严格机制声明。能耗极小化动力学（含赫布、退火、
Γ/DI 竞争电路）承载学习与读出，但系统同时依赖以下**明确给定的结构先验**，
审查时应按清单核对而非假定无先验：

- 传感维度与量程由编码器给定（概念值域自形成，维度本身不自创）；
- 自主探索的候选干预取自分位网格，控制变量法（一次只变一维、自动成对）
  躯体化为动作空间结构——方法先验，不是涌现的策略；
- 结果容差（亮度 ±0.5）、评分口径、终止 quorum 是工程选择；
- 抑制池/互斥电路是设计好的电路基元（如同皮层的篮状细胞），参数有标定记录；
- 教师真值只用于课程生成/实验台应答/评分，不进学习核（该声明经第三方
  独立验证成立）。

## 使用

```bash
npm install
npm run verify   # 编译 + 全部测试
```

```ts
import { EnergyNetwork, hebbianLearn, detectWells, ReadoutModule } from "./src/index.js";

const net = new EnergyNetwork({ neuronCount: 24, activationEnergy: 2.0, maintenanceEnergy: 0.5 });
hebbianLearn(net, [0, 1, 2, 3], 8);           // 教师呈现模式 A（8 轮 → 簇内边 0.8）
hebbianLearn(net, [0, 1], 2);                 // 簇内峰边加强到 1.0（注意：完全等权的赫布团
                                              // 是平台，严格峰检测需要一条显著更强的边——
                                              // 这是检测器边界的如实说明，见 wells.ts）
hebbianLearn(net, [12, 13, 14, 15], 8);       // 教师呈现模式 B
hebbianLearn(net, [12, 13], 2);               // 簇内峰边
const wells = detectWells(net);               // 学习后检测势阱
const readout = new ReadoutModule(wells, net.config.readoutThreshold);
readout.labelWell(0, "A");                    // 教师赋标签
const result = net.settle([0, 1]);            // 新输入：只给模式 A 的一部分
console.log(readout.identify(result.activeNeurons)); // → [{ label: "A", ... }]
```
